# GenLink splash site

Static landing and legal pages for GenLink, the genealogy research application from Cardinal Hosting Solutions LLC. Hosted on Cloudflare Pages. No build step: the repository root is the site root.

| File | Purpose |
| --- | --- |
| `index.html` | Landing page |
| `privacy.html` | Privacy Policy, the page app store listings link to |
| `terms.html` | Terms of Service |
| `404.html` | Served by Cloudflare Pages for unknown paths |
| `_headers` | Security headers applied by Cloudflare Pages |
| `robots.txt` | Allows crawling |
